Problem. Five paths return a unit to Available, but only two promote the waitlist; a buyer cancelling their own hold frees the apartment silently.

Solution. Put "unit returns to sale" behind one module in Infrastructure that owns both the state change and the promotion, so no caller can free a unit without the queue hearing about it.

  • Locality: the promise lives with the state change
  • Fixes a live defect, 3 paths
  • Promotion becomes integration-testable (Web isn't referenced by tests)
  • Two copies of try/catch logging disappear
